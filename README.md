# 动态辨识工场（Go + SQLite + HTTP + SVG）

一个本地运行的系统辨识工场：用阶跃、伪随机二值序列（PRBS）、扫频（chirp）输入激励一阶惯性加纯延迟的被控对象，记录输出（含一段时钟抖动、一段输出饱和、少量缺失），在页面上管理预处理、纯延迟与模型阶次的多个候选，并**以残差检验（而不是仅训练拟合）**判断优劣。

## 安装与演示

```bash
go mod download
go test ./... -count=1
go run ./cmd/server --listen 127.0.0.1:5550
```

浏览器打开 <http://127.0.0.1:5550>，应看到标题 **“动态辨识工场”**。数据库为空时会自动导入固定 fixture；也可在首页手动“导入固定 fixture”。

可用参数：

- `--listen` 监听地址，默认 `127.0.0.1:5550`
- `--db` SQLite 文件路径，默认 `dynidshop.db`
- `--auto-fixture=false` 关闭空库自动导入

## 数据口径（重要）

固定 fixture（`internal/fixture`，种子固定，可完全复现）对应连续对象

```
G(s) = K · e^(−L s) / (τ s + 1),   K = 2.0, τ = 0.5 s, L = 0.2 s
```

- 名义采样周期 `Ts = 0.1 s`，480 个样本，覆盖 0–48 s。
- 输入为零阶保持：6–10 s 单位阶跃；10–30 s PRBS（幅值 ±0.8，每 3 拍切换）；30–48 s 扫频正弦 0.05 → 0.8 Hz。
- 对象在细网格（`h = Ts/200`）上做 ZOH 精确物理仿真，再在“记录时刻”采样，以保证抖动段的物理含义正确。
- **时钟抖动段**：k = 200–240 的记录时刻相对名义网格有 ±12% 确定性抖动，因此原始时间戳**不是等间隔**的。
- **输出饱和段**：k = 260–290 的输出被钳位到 ±1.6，并带 `sat=1` 标志。
- 两个固定缺失样本（k = 350 输出、k = 420 输入）。

默认估计段 `[6, 20) s`、验证段 `[30, 48) s`，无重叠。

## 操作流程

1. 打开数据集页，查看原始数据（饱和段用橙色背景标出）。
2. “新建辨识运行”：
   - 划分估计段与验证段（时间单位为秒，左闭右开）。
   - 选择预处理版本：去均值（无 / 按估计段 / 按全部）、去趋势、缺失处理（线性插值 / 前向填充 / 直接报错）。
   - 非等间隔数据必须勾选“重采样为等步网格”：输入按 ZOH 最近时刻对齐，输出线性插值；**不勾选时直接拒绝，不把抖动数据伪装成离散等步模型**。
   - 饱和样本默认只参与显示与诊断；勾选后才进入拟合。
   - 添加任意多个候选：`ARX`（A(q)y=B(q)u）、`SS`（FIR+ERA 子空间，再还原差分模型）、`FO`（受限一阶，|a|≤0.999），每个候选独立指定阶次与延迟。
3. 运行页展示：
   - 拟合 / 一步预测 / 自由仿真（段内用实测历史暖机后全反馈）时序图；
   - 残差自相关 ACF（白度）与输入-残差交叉相关 CCF（外生性、延迟方向），均带 ±1.96/√N 的 95% 置信界；
   - 每个候选的参数（FO 额外给出 τ 与稳态增益 K）、估计/验证拟合、RMSE、AIC、BIC。
4. 候选按 BIC 排序，但并列阶次请同时看 ACF/CCF：低阶模型检验通过时优先于高阶；训练拟合高不代表模型好。
5. 运行间可通过运行页参数表和导出 JSON 定位参数与样本差异；同一数据集的历史运行在数据集页列出。

## 发布阻断与验收路径

- **区间重叠阻断**：估计段与验证段有正长度重叠时，运行标记为 `blocked`，服务端在发布接口上**强制拒绝**（即使绕过页面）。可把估计段改成 `25–35`、验证段 `30–48` 复现。
- **延迟候选对比**：同一模型试两个延迟（如 `0.1 s` 与 `0.2 s`），正确延迟的验证 RMSE/BIC 更优、CCF 越界数更少；CCF 峰值落在正/负滞后会给出延迟被低估/高估的提示。
- **非等间隔**：抖动数据不勾选重采样时，运行直接返回错误“不能作为离散等步模型处理”。

## 导出、清空与复核

- 运行页“导出运行”下载 JSON，内含数据集全部样本、分段、预处理选项、候选规格与结果。
- 首页“清空数据库”删除全部数据集与运行。
- 清空后在首页“导入运行导出”上传 JSON：系统恢复数据集并按完全相同的输入**重新辨识**，重定向到“导入复核”运行页，可与导出结果逐项对照（自动化测试校验候选验证拟合一比一相等）。

## 代码结构

```
cmd/server          HTTP 服务入口
internal/ident      预处理、ARX/FO/SS 辨识、预测/仿真、ACF/CCF、运行编排
internal/fixture    固定演示数据（细网格物理仿真 + 抖动/饱和/缺失）
internal/store      SQLite 持久化（datasets / samples / runs）
internal/web        HTTP 处理器、go:embed 页面模板、SVG 图表
```

## 自动化测试

`go test ./... -count=1` 覆盖：

- 一阶参数恢复、错误延迟的 RMSE/BIC 与 CCF 更差、非等间隔拒绝、重叠判定、阶次复杂度对比、饱和默认排除、缺失处理；
- fixture 形状与真值（τ、K）恢复；
- SQLite CRUD 与清空；
- HTTP 端到端：标题、候选图表、重叠发布阻断、非等间隔报错、导出→清空→导入重算一致性。
